# Van Orton Recovery agent skills

Agent skills from [Van Orton Recovery](https://www.vanortonrecovery.com), a U.S. crypto scam recovery firm.

| Skill | What it does |
|---|---|
| [crypto-scam-first-response](skills/crypto-scam-first-response/SKILL.md) | Helps an AI assistant guide someone who just lost money or crypto to a scam: stop further losses, save evidence, report it, understand how recovery works, and choose help safely. |

## Install

```bash
npx skills add vanortonrecovery/agent-skills
```
